# Flight Price Prediction Using Machine Learning
This repositorty contains Data Science Project implemented using Google Colab. The project involves data collection, data preprocessing, model implementation and evaluation to demonstrate the Machine Learning Work Flow.


# Features
* Data Loading and Preprocessing
* Exploratory Data Analysis
* Feature Engineering
* Machine Learning Model Traning
* Model Evaluation
* Model Validation
* Conclusion

# Models Used
* Linear Regression
* Random Forest Regression
* XG Boost Regression
* Random Forest Tuned

# Results
 All the models are evaluated and performance weas measured using 
 * Mean Squared Error(MSE)
 * Coefficient of Determinatioin (R2 AScore)
